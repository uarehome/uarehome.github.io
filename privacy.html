You Are Home uploader

Privacy policy

Effective 26 November 2026

What this tool is

You Are Home uploader is a private tool used only by the owner of the YouTube channel You Are Home. It uploads that channel's videos and reads that channel's analytics. It is not offered to anyone else.

YouTube API Services

This tool uses YouTube API Services. Using it means agreeing to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data it uses

  • The channel owner's authorization. The owner signs in once with Google. The resulting access token is stored on the owner's private computer, readable only by the owner.
  • The channel's own information. It reads the channel's name and ID to make sure it uploads to the right channel.
  • The channel's own videos. It uploads them and sets their titles, descriptions and publishing times.
  • The channel's own analytics. It reads totals such as views, watch time and subscribers gained, and keeps them in the owner's private notes.

It does not access, collect or store any data about viewers or any other YouTube user. It does not use cookies, and these pages do not track visitors.

Sharing

No data is sold, shared with third parties or used for advertising.

Keeping and deleting data

Analytics totals are kept as long as they help run the channel. The owner can delete them, and the access token, at any time.

Access can be withdrawn at any time in your Google Account's third-party access settings. Withdrawing it immediately stops the tool from reaching the channel.

Changes and contact

If this policy changes, the new version is published on this page with a new date. For questions, contact the channel through its YouTube page.
